# 보이스가드 웹통화 (보이스피싱 탐지 데모)

브라우저 두 개를 WebRTC로 연결해 음성통화를 하고, **받는 쪽 기기 안에서** 상대방 음성을 실시간으로 글자로 바꾼 뒤(Vosk, 온디바이스) 보이스피싱 의심 키워드가 일정 점수 이상 쌓이면 경고합니다. 통화 음성은 어떤 서버로도 전송되지 않습니다.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 + 통화(PeerJS) + 음성인식(Vosk) + 경고 |
| `detector.js` | 키워드 탐지 로직 (CSV 읽기, 점수 계산, 자막 강조) |
| `ringtone.mp3` | 전화 수신 벨소리 |
| `make_model.sh` | 한국어 음성인식 모델을 웹용 파일로 만드는 스크립트 |
| `models/` | 만든 모델 파일이 들어가는 곳 (직접 생성) |

## 1. 음성인식 모델 준비 (처음 한 번)
맥 터미널에서 이 폴더로 이동한 뒤:
```bash
bash make_model.sh
```
`models/vosk-model-small-ko-0.22.tar.gz` (약 80MB)가 생기면 성공입니다.
브라우저는 처음 접속할 때만 이 파일을 내려받고, 이후에는 브라우저 저장소에 보관해 다시 받지 않습니다.

## 2. 내 컴퓨터에서 테스트
```bash
python3 -m http.server 8080
```
크롬에서 `http://localhost:8080` 을 **탭 두 개**로 엽니다.
1. 두 탭 모두 **시작하기** → 각 탭에 010으로 시작하는 11자리 번호가 생김 (왼쪽 위, 누르면 복사)
2. 한 탭의 키패드에서 다른 탭 번호를 누르고 초록 버튼 → 다른 탭에서 벨이 울리면 **수락**
3. 소리가 서로 울리면 한쪽은 이어폰을 쓰거나 마이크를 끄세요.

통화 없이 인식만 확인하려면 **설정 → 🎧 혼자 테스트**를 누르고 마이크에 말해 보세요.

## 화면 구성
- **키패드 / 최근기록 / 설정** 탭. 최근기록에는 통화마다 안전·의심·위험 결과가 남습니다.
- **설정 → 상대방에게 보일 이름**을 넣으면 상대 수신 화면에 번호 대신 이름이 뜹니다.
- **통화 화면 테마** (설정, 또는 통화 중 더보기에서 바꿈)
  - 실제 전화: 이름과 버튼만. 탐지는 뒤에서 계속 작동
  - 실시간 자막: 화면 가운데에 상대방 말이 자막으로, 키워드는 노란색 강조
  - 분석 모드: 자막 + 위험도 점수 막대 + 탐지 키워드 목록
- 통화 중 버튼: 자막 켜기/끄기, 시연 음성, 소리 끔, 더보기(탐지 현황·기록), 종료, 키패드

## 3. 시연 방법 (추천)
- 거는 쪽: 통화 화면의 **시연 음성** 버튼에서 실제 보이스피싱 녹음 파일(금융감독원 '그놈 목소리' 등)을 골라 송출
- 받는 쪽: 자막이 뜨고 키워드가 강조되다가 점수가 기준을 넘으면 **의심(주황) → 위험(빨강)** 경고 화면

## 4. 키워드 데이터 넣기
설정 → 파일 선택으로 CSV를 올리거나 칸에 직접 붙여넣고 **적용**.
```
키워드,가중치
안전계좌,3
검찰,2
이체
```
- 가중치를 비우면 1점 → "언급 횟수"로 판단하는 것과 같습니다.
- 엑셀에서 저장한 CSV(한글 인코딩)도 그대로 읽힙니다.
- **판단 구간(초)**: 이 시간 안에 쌓인 점수만 계산합니다 (기본 120초). 오래전 언급은 자동으로 빠집니다.
- 띄어쓰기가 달라도 인식됩니다 ("안전 계좌" = "안전계좌"). 긴 키워드를 먼저 찾기 때문에 "안전계좌"가 "계좌"로 중복 계산되지 않습니다.

## 5. 다른 기기에서 접속 (배포)
마이크는 `https://` 주소에서만 켜집니다. 폴더 전체를 정적 호스팅에 올리면 됩니다.
- **GitHub Pages**: 파일당 100MB까지라 모델 파일을 함께 올릴 수 있어 가장 간단합니다.
- **Cloudflare Pages**: 파일당 25MB 제한이 있어 모델 파일은 못 올립니다. 모델은 Cloudflare R2(공개 버킷 + CORS 허용)에 올리고, 앱의 **설정 → 음성인식 모델 주소**에 그 주소를 넣으세요.

## 알아둘 점
- 통화 연결용 서버는 PeerJS 무료 공개 서버를 씁니다(번호 연결 정보만 오가고 음성은 기기끼리 직접 전송). 학교 와이파이처럼 방화벽이 강한 곳에서는 연결이 안 될 수 있으니, 시연 땐 휴대폰 핫스팟을 준비하세요.
- 직접 PeerJS 서버를 띄웠다면 주소 뒤에 `?peer=호스트:포트` 를 붙이면 그 서버를 씁니다.
- 소형 한국어 모델이라 인식 정확도에 한계가 있습니다. 키워드가 잘 안 잡히면 "혼자 테스트"로 실제로 어떻게 받아 적히는지 보고, 그 표기(예: "오티피")를 키워드에 추가하세요.
- 크롬(PC·안드로이드) 기준으로 만들었습니다.
